AI ALGO TRADER V1
==================

This is an iPhone-first PWA prototype for the AI Algo Trader dashboard.

CURRENT VERSION
- Dark mobile dashboard
- Paper trading mode
- Start / Stop / Emergency Stop
- Demo AI signals
- Portfolio metrics
- Open-position area
- System log

IMPORTANT
This version does NOT connect to Angel One, NSE/BSE, or real-money trading.
It is intentionally a safe UI prototype.

NEXT BUILD
